# 好好照顧自己｜手機 PWA

手機優先的私人健康紀錄工具。GitHub Pages 只公開程式碼，不包含私人健康清單；資料保存在使用者自己的瀏覽器 localStorage。

## 這版新增
- 第一次使用可從空白開始，不需要 JSON。
- 可在手機直接新增、編輯、暫停、恢復、封存藥物與保健品。
- 可修改服用時段、每次數量、單位、庫存與補貨提醒門檻。
- 每週注射的名稱、劑量、單位、星期與提醒門檻可自行編輯。
- 施打紀錄保存當時的劑量與單位，之後改劑量不會改寫舊紀錄。
- 封存項目不刪除既有歷史紀錄。
- 可匯出／匯入 JSON 備份。

## 隱私
不要把 `health-tracker-backup-*.json` 或其他含私人健康資料的檔案上傳到公開 repository。
